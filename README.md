# Biblionario · Corona de Gloria

Un recorrido bíblico en español inspirado en ¿Quién quiere ser millonario?: quince preguntas, tres comodines y un millón de Coronas.

- Preguntas aleatorias por cada escalón de dificultad, con opciones mezcladas.
- Backend Next.js que valida respuestas, tiempos, comodines y premios.
- PostgreSQL y Prisma para banco de preguntas, perfiles invitados y partidas persistentes.
- Salón de la Fe con la mejor partida de cada perfil.
- Estética dorada, Sabiduría de Salomón, Preguntar a la congregación y Voz profética.

La semilla contiene 45 preguntas (3 por escalón); requiere revisión bíblica antes de publicación. Los perfiles actuales son de invitado, guardados por navegador. Las cuentas recuperables y el panel editorial forman parte del roadmap.

Consulta [instalación, pruebas y despliegue](README-LOCAL.md). Se necesita PostgreSQL configurado y sembrado para jugar. Las comprobaciones de GitHub Actions usan una base temporal de pruebas.
